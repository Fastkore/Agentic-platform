# Интерфейс Agentic Platform

- Для выпадающего выбора в формах, настройках и фильтрах используйте общий компонент `Select` из `client/Select.tsx`. Для настроек и мастеров используйте класс `settings-select`.
- При необходимости расширяйте общий компонент. Не заменяйте его нативным `<select>` и не создавайте локальные копии меню. Сохраняйте доступную подпись, управление с клавиатуры и состояние недоступности.
- Перед добавлением другого контрола проверьте, есть ли в проекте подходящий компонент. Переиспользуйте существующие стили, токены темы и иконки.
