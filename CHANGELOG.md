# Изменения

## 0.6.0 · 11 ноября 2026

Добавлена наша часть пилота входа из Fastkore по проекту контракта v1: проверка одноразового билета через доверенный HTTPS endpoint, cookie/CSRF, внешние личности, первый вход без прав, управление установками и явными связями пользователей. Объект ERP передаётся через WebView2 message API и привязывается к новому чату по действию пользователя.

SSO выключен по умолчанию. Для пилота обязательны HTTPS, конкретный доверенный proxy и выключенное исполнение Codex до приёмки изоляции. Офисный режим без SSO сохраняет прежний вход и работу с чатами. Cookie-сеанс и персональный API-ключ используют разные способы передачи; роли платформы не импортируются из ERP.

SQLite обновляется до user_version=2 с сохранением истории и учётных данных. Перед обновлением нужна резервная копия всей папки данных остановленного сервера. Откат к 0.5 требует её восстановления.

Сборка и 40 автоматических проверок, включая реальный HTTPS-транспорт на искусственных данных. Linux/Docker, настоящие ERP-методы и WPF-клиент ожидают совместной проверки. Настройка: docs/FASTKORE-SSO-PILOT.md.

## 0.5.0

SQLite, устойчивая очередь, роли, профили специалистов и реестр источников. Закрытые источники и специализированные операции ожидают изоляции; обычный чат не обходит этот запрет. 30 автоматических проверок; сохранение офисной истории и реальный ChatGPT/resume проверены.
