# Fastkore для Agent Platform

## Платформа и прикладная система

**Fastkore** — платформа для создания и работы корпоративных приложений. Сервер хранит данные, проверяет права, выполняет бизнес-логику и ведёт журнал. Пользователь работает через клиент ERP. Конфигурация (`Solution`) описывает компоненты, карточки, списки, связи, фильтры, команды, отчёты и бизнес-процессы. Компонент (`entity set`) описывает схему, а объект (`entity`) — конкретную запись, например заказ.

**Fastkore Business** — прикладная надстройка на этой платформе. Она связывает контрагентов, заказы и сметы с закупками, складом, производственными позициями и операциями, отгрузкой, документами и платежами. Например, заказ и его смета, складские движения и производственные операции имеют собственные состояния. Для вопроса «что с заказом» важно уточнить, какую часть цепочки нужно проверить.

Конкретная установка может дополнять типовую конфигурацию. Для поиска данных используйте схему и доступные инструменты целевой установки. Имена полей, GUID, связи и стадии из примеров сверяйте с этой установкой.

## Сеанс сотрудника и контекст окна

Синяя кнопка в Fastkore открывает Agent Platform в WebView2. SSO связывает сеанс с сотрудником ERP. Доступ к проектам и чату задаёт Agent Platform. Права на чтение и изменение данных определяет сервер Fastkore для сотрудника, от имени которого пришёл вызов. Изменения отражаются в журнале ERP под его учётной записью.

Окно может передать снимок активной карточки, списка или табличной части, включая идентификаторы и поддерживаемые фильтры. Для вопроса «об этой записи» используйте `entity_set_id` и `entity_id` из актуального контекста. Для вопроса «по этому списку» учитывайте его область и фильтры. При `view: "none"` сбросьте прежний контекст. Если область списка нельзя воспроизвести доступным инструментом, уточните фильтр или попросите открыть нужную карточку.

## Чем получать данные

- **MCP Fastkore Business** предоставляет предметные инструменты. Начните с инструмента по нужному процессу, например по заказу, остаткам или производственным операциям. Имена инструментов и параметры берите из каталога, доступного в текущем сеансе.
- **FastkoreCLI** — клиент командной строки, который подключается к серверу Fastkore. `data get` читает известный объект, `data query` выбирает записи по условиям. Для списка задавайте небольшой лимит, нужные поля и фильтр. `agent describe` описывает команды установленной сборки. Само описание команды не выполняет запрос в ERP.
- При подключённом чтении через Linux CLI доверенный исполнитель получает отдельный одноразовый билет для каждого запуска и подаёт его в stdin. Адрес сервера и авторизацию задаёт исполнитель. Используйте инструменты, доступные в текущем сеансе. Возможности CLI из руководства шире набора команд, который может быть открыт в Agent Platform.

- `FastkoreCLI-Agent-Guide.md` — форматы команд, чтение объектов, журнал и возможности CLI. Разделы про Windows-профиль и команды разработки относятся к самостоятельной работе с CLI.
- `Fastkore-Business-Development-Guide.md` — предметные правила для заказов, смет, склада, производства, документов и платежей.
