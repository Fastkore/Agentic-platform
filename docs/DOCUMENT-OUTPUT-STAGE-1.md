# Файлы в ответе агента. Этап 1

В изолированном исполнителе доступны Python 3 с python-docx, openpyxl, библиотеками PDF и matplotlib, LibreOffice Writer и Calc, Poppler и свободные шрифты. Пакеты Python закреплены с хешами, `pip` есть только на этапе сборки. Лимиты контейнера составляют 3 ГБ памяти и 512 процессов и потоков.

## Как агент выдаёт файлы

Для специалиста включите рабочую папку агента в настройках сервера, разрешите запись в профиле и подключите инструмент «Вложения и файлы ответа». Образец можно приложить к сообщению. Внутри задания он доступен в `input/attachments`.

Codex и GLM запускают Python в песочнице команд. Gemini и Antigravity сохраняют скрипт через `workspace_files` и запускают его через `workspace_office` с `program: "python"`. Конвертация у всех моделей идёт через `workspace_office` с `program: "fk-office"`. Передайте аргументы отдельными элементами массива.

| Аргументы `fk-office` | Результат |
| --- | --- |
| `to-pdf output/КП.docx --outdir output` | PDF в `output`. Для XLSX команда использует печатные настройки листов. |
| `recalc output/Расчёт.xlsx` | Пересчитывает XLSX на месте. Возвращает JSON с количеством формул и ошибками с именами листов и адресами ячеек. При ошибках формул код выхода ненулевой. |
| `convert input/attachments/Образец.doc docx` | Копия в новом формате в рабочей папке. Для XLS используйте `xlsx`. Место вывода можно задать через `--outdir`. |
| `pages output/КП.pdf` | PNG в новой папке `КП-pages` и список относительных путей в JSON. Для повторного рендера используйте другое имя через `--outdir`. |

В `output` кладите только файлы для выдачи. Платформа прикрепляет до 8 файлов, до 20 МБ на файл и до 60 МБ суммарно. Для согласованного вида Word и PDF используйте в DOCX установленные свободные шрифты. Например, Calibri заменяется на Carlito, Arial на Liberation Sans, Times New Roman на Liberation Serif. Укажите замену в ответе, если образец использует отсутствующий шрифт.

## Изоляция конвертации

LibreOffice использует локальный Unix-сокет при запуске. Исполнитель вызывает `fk-office` через отдельное пространство имён на базе Bubblewrap. Рабочая папка текущего задания доступна для записи, программные файлы и конфигурация LibreOffice и шрифтов доступны для чтения. Сетевое пространство, процессы, IPC и `/tmp` изолированы. LibreOffice использует собственный `/tmp` для IPC, а профиль, рабочие данные и кэш размещает внутри задания. Одновременно выполняются до двух конвертаций. Общий срок ожидания слота и конвертации составляет 120 секунд. По тайм-ауту завершается вся группа процессов.

## Локальная проверка и приёмка

Локальный тест четырёх параллельных заданий прошёл. Контейнер достиг 495 МиБ памяти и 112 процессов и потоков. Образ исполнителя вырос с 627 до 894 МБ по полю `docker image inspect .Size`. Исполнитель ответил на `/health` в тестовом контейнере с временными томами.

Соберите локальный образ и запустите проверку с тем же seccomp и лимитами, что и у рабочего контейнера. Команда использует временные тома, тестовые данные и выключенную внешнюю сеть. Она проверяет четыре параллельных задания, кириллицу в PDF, пересчёт и диагностику формул, рендер PNG, тайм-аут и границы рабочего каталога.

```powershell
docker build -f Dockerfile.codex -t agentic-platformin-codex:documents-stage1 .
Get-Content tests/document-office.smoke.mjs -Raw | docker run --rm -i --init --network none --read-only `
  --user 1000:1000 --cap-drop ALL --security-opt no-new-privileges:true `
  --security-opt seccomp=./deploy/codex-seccomp.json --memory 3g --pids-limit 512 --cpus 2 `
  --tmpfs /tmp:rw,noexec,nosuid,size=64m `
  --tmpfs /runner/jobs:rw,uid=1000,gid=1000,mode=0700,size=256m `
  --tmpfs /run/bridge-codex:rw,uid=1000,gid=1000,mode=0700 `
  --tmpfs /home/node/.codex:rw,uid=1000,gid=1000,mode=0700 `
  --entrypoint node agentic-platformin-codex:documents-stage1 --input-type=module -
```

На стенде соберите образы и проверьте запуск приложения и исполнителя по [инструкции развёртывания](CODEX-WORKER.md). В чате с указанными разрешениями попросите каждый подключённый исполнитель подготовить КП по вложенному образцу в DOCX, XLSX и PDF. Скачайте комплект из ответа, проверьте его в Word и Excel, сравните оформление DOCX и PDF, сверяйте итог с формулой в Excel и проверьте, может ли модель просмотреть PNG страницы. Повторите контрольный запрос без разрешения записи. Для замера под нагрузкой запустите четыре задания с конвертацией и запишите пики памяти и процессов на стенде.
