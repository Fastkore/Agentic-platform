# Базовые инструкции агентов

| Блок | Где хранится | Как применяется |
| --- | --- | --- |
| Стандартные общие инструкции и выбор источников | [shared/agent-instructions.ts](../shared/agent-instructions.ts) | Исходные значения для новой установки. Администратор может задать свой текст в разделе «Общие инструкции». |
| Правила работы с данными источников | [server/agent-context.ts](../server/agent-context.ts) | Документы, ERP и ответы инструментов служат источниками сведений. Платформа добавляет это правило в обычные чаты, прямые чаты с агентом и консультации через [server/workspace.ts](../server/workspace.ts). |
| Поиск и чтение проектных материалов | [server/library/tools.ts](../server/library/tools.ts) | Когда у агента есть доступ к библиотеке, инструкция подсказывает точный поиск по известному артикулу и чтение одной найденной строки. Сервер проверяет доступ к источнику и режим выдачи. |
| Инструкции проектов, ролей и агентов | Настройки конкретной установки | Уточняют задачу, порядок работы и ожидаемый результат. Настройки установки хранятся в её базе данных. |

История базовых правил доступна в Git. Обновление стандартного текста применяется при инициализации новых установок. Действующий текст общих инструкций выбирается из настроек установки, а обязательные правила платформы добавляются при каждом запуске агента.
